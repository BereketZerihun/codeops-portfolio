# BirrWatch
# What it does

1,BirrWatch is a simple currency converter.
2,Converts ETB to other currencies.
3,Uses live exchange rates.
4,Allows users to add currencies to a watchlist.
5,Saves the watchlist and selected currency in localStorage.

# API Used

1,This project uses the ExchangeRate API:
https://open.er-api.com/v6/latest/ETB
ETB is the base currency.

# How to Run

1,Open the project in VS Code.
2,Open the HTML file with Live Server.
3,Enter an ETB amount.
4,Select a currency.
5,Click convert.
6,An internet connection is required to get the exchange rates.

# Self-Check

1,Currency rates load.
2,ETB can be converted.
3,Watchlist works.
4,Currencies can be removed.
5,Data is saved in localStorage.
6,Data stays after refreshing the page.
